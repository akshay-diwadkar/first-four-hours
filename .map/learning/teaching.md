# Teaching and learning records

- [Tutor](../../skills/learning/tutor/SKILL.md): start with the explanation, tutoring, and continuing-learning modes, learner choices and how to present them, the file-writing scope with the page offer and HTML-only saves, the pointer to choosing how to teach, and Reason checkpoints.
- [Learning records](../../skills/learning/tutor/references/learning-records.md): the `.learning/<subject>/` layout, naming, the `scaffold` and `check` commands, the plain-language `START_HERE.html` page refreshed on every save, never-overwrite rule, and each lesson's `learning-record` section, where Demonstrated needs more than one task and names the representation behind each piece of evidence.
- [Study planning](../../skills/learning/tutor/references/study-planning.md): the one shared `study-plan.html` per subject, its shared `goal` section, and the Tutor-owned `learning-sequence` section that other learning skills must preserve.

Delivered content is never progress: lesson records hold only evidence the learner produced.
