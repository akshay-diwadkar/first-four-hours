# Teaching and learning records

- [Tutor](../../skills/learning/tutor/SKILL.md): start with the format question, the explanation, tutoring, and continuing-learning modes, the file-writing scope, HTML-by-default saving and its link check, the pointer to choosing how to teach, and Reason checkpoints.
- [Link check](../../skills/learning/tutor/scripts/check_links.py): the `check-links` command run on saved HTML before delivery; Examiner's copy is derived from it by `tools/validation/sync_learning_link_check.py`.
- [Learning records](../../skills/learning/tutor/references/learning-records.md): the `.learning/<subject>/` layout, naming, the plain-language `START_HERE.html` page refreshed on every save, never-overwrite rule, and each lesson's `learning-record` section, where Demonstrated needs more than one task and names the representation behind each piece of evidence.
- [Study planning](../../skills/learning/tutor/references/study-planning.md): the one shared `study-plan.html` per subject, its shared `goal` section, and the Tutor-owned `learning-sequence` section that other learning skills must preserve.

Delivered content is never progress: lesson records hold only evidence the learner produced.
