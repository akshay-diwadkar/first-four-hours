# Reference

Exact facts about the suite, for lookup. Each fact comes from source, and the source is linked.

## Skills

One row per skill. The table is generated from the skill folders, [the invocation policy](../../invocation-policy.json), each skill's `skill-protocol.json`, and each skill's `requirements.txt`. Do not edit it by hand: change the source, then run `python tools/validation/sync_skill_catalog.py --write`.

- **Domain** and **Source** come from the skill's folder, `skills/<domain>/<skill>/`.
- **Starts** is the skill's invocation mode. [Your first run](../getting-started/first-run.md) explains each mode.
- **Python** is the minimum Python version for the skill's bundled scripts. `none` means the skill is instructions only.
- **Extra packages** links the skill's own requirements file. `none` means the skill declares no packages of its own.
