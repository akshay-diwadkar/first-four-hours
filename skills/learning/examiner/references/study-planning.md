# Study plan

`.learning/<subject>/study-plan.html` is the one study plan for the subject, shared with Tutor when both are used. Read it when it exists and create it when it does not; never keep a second plan or a conflicting copy elsewhere. It is a self-contained HTML file with these sections:

- `<section id="goal">`, shared by every skill that uses the plan: what the student wants to be able to do, any deadline or examination date, and the time available, as the student states it.
- `<section id="examination-coverage">`, owned by Examiner, with one part per examination, each linking to its `exams/<exam>/` folder:
  - **Coverage:** each syllabus area as not practised, practised, secure, or needs work, judged from marked attempts and never from papers delivered, and secure only from marked answers to more than one question new to the student, never from questions they have seen before, such as in a retry; under needs work, name each diagnosed gap and link the marking that shows it for Tutor, and drop a gap only when later marking of more than one question new to the student that tests it shows it resolved;
  - **Schedule:** practice sessions, timed mocks, review, and retries, dated against the examination date and the time available less what other sections already schedule, linking each set once it exists;
  - **Results:** each marked attempt with its date, score, whether it is a retry, and a relative link to its marking.

Keep every other section, such as a learning sequence Tutor writes, exactly as it is, and change `goal` only when the student changes it. When creating the plan, add only these two sections; when the student asked for planning and an existing plan lacks one of them, add it. A new set that has not been attempted changes only the schedule; coverage and results change only from marking.

When the plan also has a learning sequence, say once in this section that coverage shows examination performance while the sequence's Progress shows understanding. They disagree on an area when coverage, from marked attempts, rates it secure while one of its topics needs revision, or needs work while it has topics and all are demonstrated. On every write to this section, add, update, or remove a note beside the affected coverage so it names each current disagreement, and let the next step you schedule or offer follow the coverage; that note and statement are not coverage, so any write may change them. When you change this section's schedule, check that every section's sessions together still fit the time available; when they do not, say so and offer choices instead of changing another section.

Schedule realistically. When the syllabus does not fit the time left after other sections, say so and offer choices such as narrower coverage or fewer full mocks instead of compressing silently. Revise coverage and the schedule from results, and tell the student what changed.
