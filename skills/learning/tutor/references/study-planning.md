# Study plan

Read this on entering continuing learning.

`.learning/<subject>/study-plan.html` is the one study plan for the subject. Read it when it exists and create it when it does not; never keep a second plan or a conflicting copy elsewhere. Make it a self-contained HTML file like a lesson, with these sections:

- `<section id="goal">`, shared by every skill that uses the plan: what the learner wants to be able to do, any deadline or examination date, and the time available, as the learner states it.
- `<section id="learning-sequence">`, owned by Tutor:
  - **Sequence:** topics in order, each with its prerequisites and, once it exists, a relative link to its lesson;
  - **Schedule:** sessions or dates that fit the available time, less what other sections already schedule, and any deadline, with review of earlier topics as spaced retrieval, where the learner answers from memory at growing intervals instead of re-reading, and milestones that show progress;
  - **Progress:** each topic as not started, taught, demonstrated, or needs revision, judged from lesson records and never from delivery alone; a topic only one task has shown stays taught.

Keep every other section, such as examination coverage another skill writes, exactly as it is, and change `goal` only when the learner changes it. When creating the plan, add only these two sections; when an existing plan lacks one of them, add it.

When the learner asks for a whole course at once, say before writing it whether each lesson will be an outline, guided notes, or a complete lesson with worked examples and checked exercises.

Schedule realistically. When the goal does not fit the time left, say so and offer choices such as a narrower goal, more time, or a later date instead of compressing silently. Revise the sequence, pacing, and schedule from demonstrated progress and tell the learner what changed. Consult `reason` before committing to a new plan or a changed sequence.
