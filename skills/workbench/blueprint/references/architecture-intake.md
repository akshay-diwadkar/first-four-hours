# Architecture intake

Architect's settled decisions are upstream authority; Blueprint owns implementation planning.

Prepare only from a receipt-valid `.first-four-hours/architectures/<slug>/architecture.md` with the README command; its bytes become `request.md`, and bad, stale, or ambiguous input returns to Architect, its receipt never repaired. Require a concrete settled target with no blocking unknown or unresolved user policy; when the architecture you rely on settles no design change, stop, unless an authoritative request supplies its own concrete target citing that authority. Contradictions return to Architect.

Reuse its settled decisions, evidence, invariants, and user policy without replaying reconnaissance or asking for reconfirmation. Gather new facts per [Bounded exploration](delegation-protocol.md), and keep new user questions under intent closure. Its paths and views are bearings, never automatic edit scope.

When a new answer changes request meaning, write a resolved request with one source declaration, its digest from the verified bytes:

```text
<!-- architecture-source: {"path":"/absolute/repo/.first-four-hours/architectures/<slug>/architecture.md","sha256":"EXACT_FILE_SHA256"} -->
```

A changed source needs a fresh request, never a silently refreshed hash. To amend a plan Construct implemented from it, add `"predecessor":"<sealed blueprint.md path>"`; intake then ignores only that plan's Locations. Carry intent, mechanism facts, protected behavior, consequences, and evidence into Goal and Current State without copying prose or making mapping artifacts. Every material imported invariant, constraint, and policy survives the [requirement trace](challenge-and-rehearsal.md#requirement-trace) as a completion condition or preservation disposition, or seal is blocked. Once sealed, the Blueprint, not the architecture, owns progress.
