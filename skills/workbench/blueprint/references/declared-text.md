# Declared text

Exact text (`**Exact:**`) is earned only for textual data whose bytes are the decision: deliverable wording, configuration, a format, pattern, or diagnostic string, a pure data file, a delicate anchored line edit, or a mechanical rename; on an executable file each block changes at most two lines. It proves bytes, never semantic completeness, so behavior steps stay specified.

Write new step proof in prose: location and owner, then each case's inputs, observable result, and the compliant-but-wrong implementation it rejects, placed at the cheapest boundary exposing it, with no mock replacing the operation whose result it claims. `**Frozen:**` holds only test data whose exact bytes discriminate; the `**Proof run:**` runs the proof. A new regression's `Red:` names the defect current source shows, never how it surfaces; Construct judges the observed failure. Shape the Proof run so its red is observable under the repository's runner traps. When the host cannot produce the red, record why and where it can in Current State, keep the regression as passing proof, and start its condition with `Owner gate:` naming who confirms it there.

Plan a break-the-code check only when ordinary proof could pass a named wrong outcome: retained proof, placed per the repository's test rules, run after its target exists and never as a `Red:`, passing unmutated and failing after a named mutation of Exact or Frozen bytes on a temporary or in-memory copy, never the worktree.

`**Exact:** `path`` or `**Frozen:** `path`` names one of the instruction's Locations. A `new` target takes one closed, unindented fenced block, its whole content; an `existing` one takes a block, a standalone `**With:**` line, and a second block replacing the first's whole lines (quote the full content to rewrite it; an empty file or a last line without a newline stays specified). Block text is the LF lines between fences, CRLF read as LF; an instruction/Location/State sequence, or a same-character fence at least as long as the outer one, inside it is ambiguous. One `**Proof run:** `command`` follows the Run rules, then optional `Timeout:` and `Red:` once each and a required `Expect:`. In Implementation and Verification, a line starting `Exact`, `Frozen`, `With`, `Proof`, `Red`, or `Incomplete` and a colon is reserved: spell it as above (bold for the first four; any case, optional indent and `-` or `*` marker) or fence it.

Construct applies each block at its anchor and reproves it after every later instruction, so no specified edit may touch a block's replaced text before it or its text after it; widen a refused block with unchanged neighbouring lines.
