# Broad Discovery

Load only for an explicitly broad request such as repository-wide risk discovery, broad code-quality diagnosis, or asking what is materially worth improving across a project.

Broad does not mean exhaustive taxonomy, fixed subsystem checklist, pass matrix, quota, or mandatory category coverage. Bound the pass by the user's objective, likely material risk or leverage surfaces, current evidence, available time, and an explicit stop condition.

Start with surfaces where consequence and plausibility are highest. Adjacent expansion is earned only when current evidence shows it can materially change the diagnosis or add another independently actionable finding. State material limitations for important surfaces not inspected.

A broad pass still uses the [finding gate](diagnosis-techniques.md#finding-gate) and bounded completeness from Diagnosis Techniques; stop when remaining uninspected space would not be decision-useful for the stated objective.
