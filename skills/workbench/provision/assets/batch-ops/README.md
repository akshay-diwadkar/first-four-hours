# batch-ops

The optional MCP server Provision offers. Its `batch_read`, `batch_run`, and `batch_edit` tools batch reads, commands, and edits with rollback into one call; [batch-ops](../../references/batch-ops.md) says how Provision sets it up.

Version: 3.2.0

This is Provision's version, kept equal by the repository validator. On a rerun, Provision compares it with the same line beside the server its entry runs and offers an update when they differ, so a Provision change that leaves the server as it was can still offer one. Each report's title names a `build` hash of the code actually running.
