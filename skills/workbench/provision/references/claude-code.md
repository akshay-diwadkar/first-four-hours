# Claude Code

Checked 2026-11-16 against Claude Code 2.1.325, https://code.claude.com/docs/en/sub-agents, https://code.claude.com/docs/en/settings, and https://code.claude.com/docs/en/model-config.

- **Directory:** `.claude/agents/` for a project install; `~/.claude/agents/` for a user install, which includes the plugin.
- **File:** `<name>.md`: YAML frontmatter with `name`, `description`, `tools`, `model`, and `effort` when chosen, then the instructions as the body. Hyphens are allowed in `name`.
- **Capabilities:** `tools` is an enforced allowlist. Read and search: `Read, Grep, Glob`. Shell: add `Bash`. Web: add `WebSearch, WebFetch`. `ffh-constructor`: add `Edit, Write, Bash, Skill`. Leaving out every edit and agent tool blocks file-tool edits, and leaving out `Agent` blocks spawning. A granted `Bash` can still change files, so a read-only agent's no-edit limit needs the user's choice.
- **batch-ops agents:** list `mcp__batch-ops__batch_read` in place of `Read, Grep, Glob`, `mcp__batch-ops__batch_run` in place of `Bash`, and `mcp__batch-ops__batch_edit` in place of `Edit, Write`.
- **Models:** `model` takes an alias or a full model ID from the model configuration page, which also lists the effort levels each model supports; the user's `/model` picker shows what their account offers. `effort` takes one of those levels; on a model other than the session's, set it explicitly or leave it out.
- **Loaded:** the agent appears in `/agents`, which shows its model and tools, and among the subagent types the session can launch. Files are picked up within seconds, except that an `agents` directory created during the session needs a restart.
- **batch-ops:** checked 2026-11-16 against Claude Code 2.1.325 and https://code.claude.com/docs/en/mcp. Scope `local` for a project install (private to you, unlike `project`, which shares this machine's paths through `.mcp.json`), `user` for a user install. Add with `claude mcp add --scope <scope> batch-ops -- <python> <server>`; `claude mcp list` lists every scope's servers with their health, `claude mcp get batch-ops` shows one, and `claude mcp remove --scope <scope> batch-ops` removes one. Connected: `claude mcp list` shows it `Connected`.
- **Guard:** checked 2026-11-24 against Claude Code 2.1.331 and https://code.claude.com/docs/en/hooks. Append `{"matcher": "Read|Grep|Glob|Edit|Write|Bash|PowerShell", "hooks": [{"type": "command", "command": "<python>", "args": ["-c", "<launcher>", "<guard>"], "timeout": 10}]}` to `hooks.PreToolUse` in `~/.claude/settings.json`, or, for a project install whose `.claude/settings.local.json` `git check-ignore` reports ignored, in that file. Parse the file after writing and restore it if that fails, since a malformed file drops all its settings. A settings folder created this session waits for a restart.
- **Instructions file:** checked 2026-11-19 against https://code.claude.com/docs/en/memory. Project: `CLAUDE.md`, or `.claude/CLAUDE.md` if only that exists, but `AGENTS.md` if the project has only that, since a new `CLAUDE.md` would hide it. User: `~/.claude/CLAUDE.md`.
