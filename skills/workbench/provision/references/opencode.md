# OpenCode

Checked 2026-11-16 against the documentation only, with no installed version: https://opencode.ai/docs/agents/, https://opencode.ai/docs/permissions/, https://opencode.ai/docs/tools/, https://opencode.ai/docs/config/, https://opencode.ai/docs/models/, and https://opencode.ai/docs/cli/. Re-check each fact you use against these pages on every run.

- **Directory:** `.opencode/agents/` for a project install; `~/.config/opencode/agents/` for a user install.
- **File:** `<name>.md`, where the filename is the agent's name: YAML frontmatter with `description`, `mode: subagent`, `model`, and `permissions`, then the instructions as the body. These are the V2 keys; never write the deprecated V1 `permission`, `tools`, or `task`, and rewrite an agent that has them.
- **Name:** use `ffh_<role>`; the documentation's examples do not establish that hyphens work.
- **Capabilities:** `permissions` is an enforced, ordered list of rules, each with `action`, `resource`, and `effect` (`allow`, `ask`, or `deny`); the last matching rule wins and an unmatched action asks. Start with `{action: "*", resource: "*", effect: deny}`, then allow with resource `"*"`: for every agent `read`, `glob`, and `grep`; `shell` for `ffh_challenger`, `ffh_reviewer`, `ffh_constructor`, and `ffh_planner`; `webfetch` and `websearch` for `ffh_researcher`; and `edit` and `skill` for `ffh_constructor` and `ffh_planner`. Those two also get `external_directory` for the installed skills folder and the system temporary folder, where Construct's and Blueprint's files live, and `ffh_planner` gets `subagent` once each for `ffh_challenger`, `ffh_evidence`, and `ffh_researcher`. An allowed `shell` can still change files, so a read-only agent's no-edit limit needs the user's choice.
- **batch-ops agents:** allow `batch-ops_batch_read` in place of `read`, `glob`, and `grep`, `batch-ops_batch_run` in place of `shell`, and `batch-ops_batch_edit` in place of `edit`. The deny-all rule also denies `execute`, so OpenCode lists these tools directly. Whether per-tool MCP allows after a deny-all rule take effect is not documented: report each batch-ops agent unverified until the user confirms in a new session that it can call them. batch-ops counts as connected for that choice when `opencode mcp list` shows it `connected`.
- **Nesting:** `experimental.subagent_depth`, default 1, stops a subagent from starting one. Read it in the project's `opencode.json`, which wins, then `~/.config/opencode/opencode.json` (or `.jsonc`). When it is under 2, offer to set it to 2 in the user file, the subagent-depth setting Provision writes, changing nothing else there, and write `ffh_planner` only after a yes. Offer to remove it when `ffh_planner` is dropped or on uninstall, saying Provision may have set it.
- **Models:** `opencode models` lists `provider/model` IDs for the user's authenticated providers; add `--refresh` to fetch newly added models. `model` takes one of those IDs.
- **Effort:** `model` takes `provider/model#<variant>`, and a model's variants often set reasoning effort. Offer effort only as a variant the chosen model defines; otherwise leave it out and say so.
- **Cache:** `settings.cache.ttl` applies to a whole provider or model, never one agent, so `ffh_planner` keeps the default.
- **Loaded:** ask the user to confirm in a new session that the agent appears in the `@` menu and runs on the chosen model, that a read-only agent is refused an edit, so `permissions` is enforced, and that `ffh_planner` can start `ffh_challenger`; until they confirm, it stays written but unverified.
- **batch-ops:** https://opencode.ai/docs/mcp-servers/. Register it globally on either install, since project configuration is usually committed and would carry this machine's paths, and tell the user it applies to every project. Add with `opencode mcp add batch-ops --global -- <python> <server>`. That page names the configuration files and the entry's key path, which differ between versions; read existing entries there. No command removes one: delete only that entry, leaving the rest of the file unchanged. Connected: `opencode mcp list` shows it `connected`.
- **Instructions file:** https://opencode.ai/docs/rules/. Project: `AGENTS.md`, or `CLAUDE.md` if only that exists. User: `~/.config/opencode/AGENTS.md`, or `~/.claude/CLAUDE.md` if only that exists.
